# Reference List (IIE Harvard)

This consolidated list covers every source cited in code comments and the README across Parts 1 and 2 of the HustleHub+ POE. In-text citations in the code use the IIE Harvard author-date form, for example `(SARS, 2026)`, and the entries below are in alphabetical order. Where one author has two sources in the same year, a letter suffix (2026a, 2026b) tells them apart.
